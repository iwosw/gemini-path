# Диагностика и DPI на Windows (дополнительно)

Этот раздел предназначен для **исходного ZIP репозитория**, не для установленного GUI. Запуск `GeminiPath.cmd` требует PowerShell 5.1; сам движок DPI работает только с правами администратора. GUI-патчер в установщике этих прав обычно не требует.

## Быстрый старт

1. В распакованной папке репозитория выполните `GeminiPath.cmd doctor`. Проверка DNS, TCP:443 и HTTPS для `example.com` (контрольный адрес) и доменов из `domains.txt` делает прямые запросы без системного HTTP-прокси. Успешный HTTP-ответ **не доказывает**, что чат или генерация доступна аккаунту.
2. Выполните `GeminiPath.cmd install`. Скрипт скачает официальный [GoodbyeDPI 0.2.2](https://github.com/ValdikSS/GoodbyeDPI/releases/tag/0.2.2), проверит SHA-256 `00A2F8B99CD817F8C7FC4C449033015F039D18AF213DE78CB66BF202277C0628` и распакует в игнорируемую Git папку `vendor/`.
3. Откройте **Командную строку от имени администратора**, перейдите в папку проекта и выполните `GeminiPath.cmd start`. Снова запустите `GeminiPath.cmd doctor`, затем проверьте **реальный запрос** в браузере, Antigravity и CLI.
4. Если простой режим не помог, запустите `GeminiPath.cmd stop`, затем `GeminiPath.cmd start -Mode fake`. Остановить режим в любое время: `GeminiPath.cmd stop`.

| Команда | Действие |
| --- | --- |
| `GeminiPath.cmd doctor` | DNS/TCP/HTTPS без входа в аккаунт |
| `GeminiPath.cmd install` | Скачать движок и проверить хеш |
| `GeminiPath.cmd start` | Фрагментировать TLS ClientHello для доменов из `domains.txt` |
| `GeminiPath.cmd start -Mode fake` | Дополнительно использовать ложные запросы с неверным checksum/SEQ |
| `GeminiPath.cmd status` | Проверить собственный процесс |
| `GeminiPath.cmd stop` | Остановить только запущенный проектом процесс |

`domains.txt` содержит имена хостов без `https://` и `*`; GoodbyeDPI учитывает и их поддомены. Движок видит TCP 80/443 на сетевом уровне и выбирает трафик по HTTP Host/TLS SNI; остальной TCP-трафик через фильтр проходит без изменений. Изменения системного DNS, прокси, `hosts`, автозапуска или службы не делаются. Глобальная блокировка QUIC (`-q`) не включена: она затронула бы всю Windows.

**Если HTTPS отвечает, а чат нет:** `HTTP 200/302/403/404` в `doctor` говорит только об ответе от адреса, а не о пригодности аккаунта. Chromium может использовать QUIC по UDP/443, который этот точечный режим не обрабатывает: для проверки временно отключите QUIC только в выбранном браузере и перезапустите его. При `DNS failed/timeout` исправлять нужно разрешение имени; при `example.com failed` проверяйте основное соединение. При проблеме с WinDivert смотрите окно движка и завершите другие перехватчики для эксперимента. Не отключайте защиту Windows ради запуска.

Команды `GeminiPath.cmd ag-scan`, `ag-patch`, `ag-restore` остаются для портативного патчера с Python 3.10+. Для новичка рекомендуем [готовый GUI-установщик](../README.md#установка-за-минуту).
